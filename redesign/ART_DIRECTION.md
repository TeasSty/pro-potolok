# ART DIRECTION — PRO Потолок

**Концепция:** «Свет меняет пространство»  
**Стадия:** подготовка к редизайну (без реализации)  
**Ориентиры бренда:** сообщество VK `propotolok1`, обложка шоурума, скриншоты/макеты с бирюзово-зелёным полем — **не копировать** оформление VK и не повторять старый лендинг.

---

## 1. Идея

Сайт рассказывает, как тонкая линия света и точный профиль меняют ощущение комнаты.  
Посетитель не «читает каталог услуг», а проходит через смену световых сцен: от большого архитектурного кадра → к языку систем → к реальным интерьерам → к устройству узла → к разговору о заказе.

**Характер бренда:** точный · спокойный · архитектурный · локальный · технологичный без холодного SaaS.

**Один главный жест:** *световая линия как композиционный разрез* — тонкая горизонталь/диагональ бирюзы или белого света, которая режет поля, связывает секции и рифмуется с реальными треками на фото. Не декор «ради красоты», а метафора продукта.

Вторичные жесты (не больше двух):

1. Смена тональности поля (светлое нейтральное ↔ графит ↔ бирюзовый пласт).  
2. Резкий скачок масштаба фото (комната целиком → макро узла).

---

## 2. Визуальный язык

### Что делаем

- Фотографии потолков и света — главный материал, не фон «под текст».  
- Типографика крупная, с архитектурными переносами; бренд на первом экране читается как сигнал, а не мелкий логотип в шапке.  
- Сетка **намеренно нарушенная**: разные ширины колонок, вылеты кадров за поля контейнера, смещение текстовых блоков относительно фото.  
- Пустое пространство — инструмент ритма, не «дыра от недоделанной вёрстки».  
- Бирюзовый — акцент идентичности (кнопки, линия, подписи, одно крупное цветовое поле), не заливка всего сайта.

### Чего избегаем

- Типовой стек: hero → 4 преимущества → 3 карточки → галерея → отзывы → форма.  
- Одинаковые карточки решений в один ряд.  
- Три колонки «иконка + заголовок + текст».  
- Фиолетовые градиенты, glow, glass, «AI-SaaS» вид.  
- Декоративные блобы, стикеры, плавающие бейджи на фото.  
- Повтор одной сетки в каждой секции.  
- Фейковое разнообразие проектов из ракурсов одного объекта.  
- Неподтверждённые цифры, отзывы, названия объектов.

## 3. Цветовая палитра

Ориентир бирюзы по обложке VK / макетным полям: **`#28565A`**.  
Это **не официальный brand book HEX**, а рабочий цвет, снятый визуально. Перед продакшеном сверить с владельцем.

| Роль | HEX (рабочий) | Применение |
|---|---|---|
| **Brand teal** | `#28565A` | Акцентные плоскости, primary CTA на светлом, линия-жест, мелкие маркеры |
| **Teal deep** | `#1C3D41` | Тёмный вариант бренда, hover, ночные поля |
| **Graphite** | `#161616` | Основной текст на светлом, тёмные сцены |
| **Ink soft** | `#2A2A2A` | Вторичный текст |
| **Paper** | `#F4F2EC` | Светлые поля (нейтральный тёплый, не «крем ради крема») |
| **Paper cool** | `#EEF1F0` | Альтернативное светлое поле рядом с бирюзой |
| **White** | `#FFFFFF` | Текст на тёмном/бирюзовом, кнопки |
| **Line** | `rgba(40,86,90,0.35)` / белая 20% | Тонкие разделители, выноски схемы |
| **Photo scrim** | чёрный 0–70% градиент | Читаемость текста на фото — минимально |

Запрет: не красить весь сайт в бирюзу; не делать «бирюзовый hero с белым текстом» как единственный приём на всех экранах.

## 4. Типографика

Текущий сайт: Golos Text. Для нового языка — **более выразительная пара**, без Inter/Roboto/Arial как display.

**Предложение (к утверждению):**

| Роль | Шрифт | Почему |
|---|---|---|
| Display / заголовки | **Manrope** или **Unbounded** (кириллица) — выбрать один после теста на «Потолок —» | Геометрия, современность, хорошо с архитектурными кадрами |
| Body / UI | **Golos Text** или **Manrope** в меньших кеглях | Читаемость, уже знаком проекту |

Если оставить только Golos — усилить иерархию кеглями и трекингом, не «карточной» одинаковостью.

Правила:

- H1 на первом экране: крупный, 2–4 строки, бренд не слабее заголовка.  
- Подписи к фото: мелкий caps / tracked label + короткое имя роли кадра (не выдуманный адрес).  
- Технический блок: моноширинный или узкий caps для выносок схемы.  
- Не больше двух начертаний акцентов на экране.

## 5. Композиционные принципы

1. **Один главный кадр на сцену** — остальное подчинено.  
2. **Смена масштаба каждые 1–2 экрана:** комната → деталь → схема → снова комната.  
3. **Асимметрия с якорем:** текст всегда визуально «прилипает» к фото (общая базовая линия, общая кромка, общая световая линия), без парящих колонок в пустоте.  
4. **Ритм полей:** Paper → Photo-dark → Paper → Teal plate → Graphite close.  
5. **Световая линия-жест** пересекает минимум два смысловых перехода (например, из opening в решения и из интерьеров в конструкцию).  
6. **Плотность:** коммерческие CTA компактные; не размазывать кнопки по всему viewport.  
7. **Честность кадра:** один объект = одна история; соседние кадры — другие объекты или явные «детали того же».

## 6. Визуальные переходы

| Переход | Приём |
|---|---|
| Opening → Решения | Кадр «сжимается» или уходит вверх; появляется бумажное поле; линия-жест тянется в первый solution-кадр |
| Решения → Интерьеры | Полный уход в тёмный/графитовый пласт; первый большой интерьер без карточек |
| Интерьеры → Конструкция | Резкая смена: фото → чертёжная плоскость (светлая), крупная схема |
| Конструкция → Аудитории | Бирюзовый «плато» на всю ширину разрезает страницу; слева/справа разные режимы (не twin-cards) |
| Аудитории → Контакт | Тишина: меньше фото, больше типографики + телефон |

Motion (когда дойдёт до кода): короткие (200–400 ms) сдвиги/маски по линии; без parallax-цирка; `prefers-reduced-motion`.

## 7. Поведение элементов

| Элемент | Поведение |
|---|---|
| Фото | Лёгкий scale на hover только если это интерактив (проект/решение); иначе статично |
| CTA primary | Заливка teal или white-on-teal; ясный фокус |
| CTA secondary | Текстовая ссылка с линией, не «вторая таблетка» рядом всегда |
| Навигация | На desktop — спокойная; на mobile — **обязательное** меню (сейчас на live его нет) |
| Телефон | Всегда доступен |
| «Смотреть» | Либо реальный lightbox/якорь, либо не показывать кнопку |
| Схема | Крупная; подписи снаружи выносок; без хаоса текста поверх |

Интерактивы не имитировать: нет бутафорского слайдера 01/02/03, нет мёртвых «Все проекты».

---

## 8. Мобильная версия

- Первый экран: бренд + одна фраза + один CTA + один доминирующий кадр (full-bleed).  
- Решения: вертикальная лента «фото → подпись», чередование выравнивания влево/вправо, без 2×2 карточек.  
- Интерьеры: один крупный кадр на экран + тонкая полоса следующего; свайп допустим, но не обязателен.  
- Схема: схема на всю ширину, подписи стеком под ней (не микротекст на SVG).  
- Аудитории: две сцены одна под другой, не «две колонки сжатые».  
- Меню: бургер или нижняя компактная панель с телефоном.

## 9. Коммерческая логика

Посетитель за 5–10 секунд понимает:

1. Это **натяжные потолки и профильные/световые системы в Вологде**.  
2. Есть **готовые примеры** (реальные фото).  
3. Можно **позвонить** или написать в VK / оставить заявку (когда форма появится).  
4. Компания работает и с **частными**, и с **дизайнерами**.

CTA-иерархия:

1. Позвонить / обсудить проект  
2. Посмотреть интерьеры (якорь)  
3. Дизайнерам — отдельный спокойный вход  

Не продавать цифрами, которых нет. Год «с 2009» — только если подтверждён (в брифе указан как известный из VK). Телефон **+7 (911) 501-12-02** — известный рабочий контакт.

## 11. Что сознательно не берём из текущего сайта

- Чёрно-бежевый «архив каталога» без бирюзовой идентичности.  
- Stats-полоса с неподтверждёнными «3000» и «5,0 / 300 отзывов» (пока нет сверки).
