## 5. Проблемы архива (для реализации позже)

1. Мало **разных** законченных интерьеров высокого разрешения: фактически 1–2 сильных жилых объекта + серия санузлов/узлов.  
2. Риск «фейкового разнообразия» объекта A.  
3. Много телефонных 9:16 — ограничение для широких композиций.  
4. Рекламные VK-посты нельзя выдавать за портфолио.  
5. В старом макете (`mockup-ref`) фигурировало название вроде «Квартира на Ленинградской» — **не подтверждено** материалами архива; в новом сайте не использовать без владельца.  
6. Второй телефон на обложке VK — не смешивать с сайтом без сверки.
